# Beastkin ethnicities: human base + species ear gene + hair color matched to
# the ear/fur color. hair_color box = { x_min y_min x_max y_max } in the hair
# palette (x = hue: neutral grey left -> red right; y = light top -> dark bottom).
# The exact x=0 column is pure neutral grey/white, so grey/white boxes pin x~0.
# east_asian-template kin also override hairstyles with range { 0.1 1.0 } to skip
# the "empty" (bald) entry at the head of east_asian_hairstyles.
# gene_age = ova_beastkin_aging: ages like old_1 but WITHOUT hair greying, so
# beastkin keep their fur-matched hair color into old age.
