# Reyorn harem storyline (John Paradox) - static modifiers.
# Every date beat in events/ova_rey_events.txt now carries a SECOND effect that is
# the literal consequence of what its option text says John did, and most of those
# consequences land here. The rule the whole file exists to serve:
#
#   a courtship option's non-affection effect must be readable straight off the
#   option text. Help her break the cartel -> her routes reopen. Pay the boy's
#   fine -> the treasury pays it. Burn the manuscript -> the republic loses the
#   knowledge in it. Nothing generic, nothing interchangeable.
#
# STATE modifiers (applied via s:STATE_<X>.region_state:REY) carry only state_* /
# building_group_* types; COUNTRY modifiers carry only country_* / interest_group_*
# types. Mixing them silently drops half the modifier, so the two are kept apart
# and labelled below. All modifier-type keys verified against
# C:\Program Files (x86)\Steam\steamapps\common\Victoria 3\game\common\modifier_type_definitions\.
# Icons reused from vanilla gfx/interface/icons/timed_modifier_icons/ (no new art).
# Every key below has a display-name loc entry in
# localization/replace/english/ova_rey_l_english.yml.
