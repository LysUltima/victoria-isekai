# METTERNICH_SYSTEM / ZOLLVEREIN entries): a single ungated `principle = ` at creation (vanilla proves
# this is NOT blocked by that principle's own `visible = { has_dlc_feature = power_bloc_features }`
# UI-only gate — Britain's history entry sets principle_vassalization_1 unconditionally despite that
# principle having exactly that visible gate). Only a *second*, later-added principle needs the
# `if = { limit = { has_dlc_feature = power_bloc_features } power_bloc = { add_principle = ... } } }`
# wrapper vanilla uses (see c:DEM below, pre-existing, untouched) — our three JE-storyline blocs only

# c:DEM's own pre-existing empire bloc is left as-is (not part of this deliverable, but it is fully
# vanilla-verified: identity_sovereign_empire + principle_vassalization_1 mirror the vanilla British
