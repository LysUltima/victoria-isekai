# new law_martial_sect governance principle added to its lawgroup_governance_principles block.
# Re-declaring an ideology by name fully REPLACES the vanilla definition (no deep merge), so each
# ideology below reproduces its complete vanilla content verbatim plus the single new line. Any
# ideology NOT listed here simply treats law_martial_sect as neutral. Keep these in sync if the
# vanilla ideologies change.
#
# Thematic stance: the Martial Sect is a militarist, autocratic, tradition-bound order where the
# strongest cultivator rules. Reactionaries/militarists/feudal-traditionalists approve; liberals,
# republicans, socialists, communists and anarchists reject rule-by-force.
#
# law_academy needs no entries here: it is a variant (parent = law_theocracy) and inherits its
# parent's ideological stances.
