### Xianxia jianghu flavor events (Agent C, sole owner of this file)
# Namespace ova_xianxia_flavor. Not storyline-specific, so it no longer depends on a journal
# entry: fired directly from the regular on_action xianxia_flavor_monthly_events
# (common/on_actions/ova_flavor_on_actions.txt), hooked into the engine's on_monthly_pulse_country
# (common/on_actions/00_code_on_actions.txt) - do not renumber these fixed ids, the on_action's
# weights are wired against them. This used to also roll (subsets, or in je_ova_xianxia_jianghu's
# case entirely) from the on_monthly_pulse random_events of je_ova_xianxia_jianghu (now deleted -
# it was a pure flavor carrier with no victory condition of its own) and je_ova_xianxia_blood_lotus
# / je_ova_xianxia_jade_mandate / je_ova_xianxia_righteous_banner / je_ova_xianxia_covenant_banner
# (still extant storyline JEs, whose pulse no longer touches flavor); every event's own trigger
# (ova_xianxia_is_participant_trigger, the same gate jianghu used) already covers the full eligible
# population. These are lived-in color for every
# one of the 13 sects plus FEN/YAO while the dao war is undecided - not the Destined One's own
# chain (that is Agent B's ova_xianxia namespace) and not champion XP/renown bookkeeping (the
# universal champion JE owns that). Uses only verified vanilla effects/triggers, Agent-A-owned
# ova_xianxia_* triggers/variables, champion-foundation ova_champion_* effects/triggers, and the
# ova_xianxia_flavor_* modifiers defined in common/static_modifiers/ova_xianxia_flavor_modifiers.txt.
#
#  .1  the pill-furnace explosion        (jianghu economy: alchemy hall mishap)
#  .2  the jade-slip auction season      (jianghu economy: auction hosting fees)
#  .3  a wandering sword immortal asks for tea   (champion duel flavor)
#  .4  the incense economy of the ancestral shrines   (jianghu economy: shrine tolls)
#  .5  counterfeit cultivation manuals flood the market   (jianghu economy: manual forgeries)
#  .6  a spirit-beast tide out of the hills   (jianghu economy: hunting throughput)
#  .7  two elders feud over a qi vein    (jianghu economy: mining throughput / politics)
#  .8  the mortal town at the mountain foot petitions the sect   (politics: loyalists/radicals)
#  .9  a demonic preacher at the crossroads   (works for demonic hosts too - conversion flavor)
#  .10 the heavenly omen nobody can read (renown/prestige trifle)
#  .11 a rogue cultivator turns himself in with a stolen treasure   (jianghu economy)
#  .12 the sword tablet no junior can lift   (champion duel flavor)
#  .13 the matchmaker season             (sect politics: marriage-alliance gossip)
#  .14 storytellers retell the Destined Ones wrong

namespace = ova_xianxia_flavor

ova_xianxia_flavor.1 = { # the pill-furnace explosion
	type = country_event
	placement = root
	duration = 3

	title = ova_xianxia_flavor.1.t
	desc = ova_xianxia_flavor.1.d
	flavor = ova_xianxia_flavor.1.f

	event_image = { video = "unspecific_fire" }

	icon = "gfx/interface/icons/event_icons/event_fire.dds"

	trigger = {
		ova_xianxia_is_participant_trigger = yes
	}

	immediate = { }

	option = { # pay for repairs and hush it up
		name = ova_xianxia_flavor.1.a

		add_treasury = { value = money_amount_multiplier_small multiply = -1 }

		add_radicals = { value = small_radicals }
		add_modifier = { name = ova_xianxia_flavor_furnace_scars days = 365 }
	}
}
